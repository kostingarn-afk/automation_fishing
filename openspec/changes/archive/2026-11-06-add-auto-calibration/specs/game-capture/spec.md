# Spec Delta

## MODIFIED Requirements

### Requirement: Захват клиентской области

Система SHALL захватывать кадр клиентской области окна (а не всего экрана) и SHALL захватывать
произвольную прямоугольную область внутри неё, вычисленную по маске воды. Если область по воде
не определена, система SHALL использовать доли по умолчанию от клиентской области по каждой оси
отдельно. Кадр SHALL быть доступен как массив пикселей для последующего анализа.

#### Scenario: Захват ROI

- **WHEN** область поиска вычислена по маске воды на кадре клиента 1920x1080
- **THEN** кадр имеет размер этой области, содержит точку заброса поплавка и воду, а красные
  объекты сцены (костёр, доспех персонажа) остаются вне окна проверки поплавка

#### Scenario: Фолбэк на доли по умолчанию

- **WHEN** вода на кадре не найдена и область по воде не определена
- **THEN** запрошенный ROI берётся с долями 0.35–0.65 по горизонтали и 0.20–0.50 по вертикали
  и для клиентской области 1920x1080 имеет размер 576x324 пикселя

#### Scenario: Кадр не получен

- **WHEN** захват возвращает пустой кадр, кадр нулевого размера или однородный чёрный кадр
- **THEN** система сообщает об отказе слоя захвата и помечает цикл маркером `WIN_FAIL`
